3.6 估值锚定
方法适用场景公式/标准
PE 估值稳定盈利公司PE < 行业中位数 × 0.8 为低估
PEG 估值成长股PEG < 1 低估，1-1.5 合理，> 1.5 高估
PB 估值银行、地产、周期股PB < 1 为安全边际
DCF 折现现金流稳定的企业内在价值 = Σ FCF / (1+r)^t
相对估值同行业横向比较指标低于行业均值 + 有催化剂 = 机会

核心原则：不追高估值，不在泡沫中买入好公司。估值决定买入价格，基本面决定买入方向。

四买入策略
4.1 趋势突破买入法

理论：价格突破关键阻力位，说明多方力量主导，趋势启动。

入场条件（全部满足）：
1. 收盘价 > HHV(HIGH, 20)（突破20日最高价）
   且当日成交量 > MA(VOL, 20) × 1.5（放量确认）
2. MACD(12,26,9) 的 DIF 线在 DEA 线上方（金叉状态）
   且 MACD柱状图 > 0（动能确认）
3. 大盘非熊市状态（按 2.2 多维度判定）
4. 基本面符合选股标准 + 未触发排雷清单
5. 盈亏比 >= 2:1（目标位与止损位的距离比）

买入仓位：计划总仓位的 50%（首批）
确认加仓：突破后回踩确认不破突破位，加仓 30%
趋势加速：放量创新高，加仓 20%
4.2 回调买入法

理论：上升趋势中的回调到关键支撑位是低风险买点。

入场条件（全部满足）：
1. 大趋势向上：收盘价 > MA(CLOSE, 60)
   且 MA(CLOSE, 60) > REF(MA(CLOSE, 60), 5)（均线拐头向上）
2. 股价回调至 MA(CLOSE, 20) 或 MA(CLOSE, 60) 附近（偏差在 ±2% 以内）
3. 回调缩量：MA(VOL, 5) < MA(VOL, 20) × 0.7
4. 出现企稳K线（满足任一）：
   - 锤子线（下影线 > 实体的2倍）
   - 看涨吞没（今日阳线实体完全包住前日阴线）
   - 十字星（开盘价≈收盘价，且出现在支撑位）
5. 盈亏比 >= 2:1

买入仓位：计划总仓位的 60%
止损位：支撑位下方 2 × ATR(14)
确认加仓：放量反弹突破回调前高，加仓 40%
4.3 底部右侧确认买入法
重要定位：本策略为高难度策略，实盘资金不超过总资金 5%。
建议先用模拟盘练习至少 10 次信号后再实盘。
不做左侧抄底，只做右侧确认后的买入。
入场条件（至少满足5项，其中1-3为必选项）：
必选项：
1. 股价从高点跌幅 > 40%（空间够大）
2. 出现明确的底部形态（早晨之星、底部吞没、W底突破颈线）
3. 大盘同期见底企稳（至少不再创新低）

加分项（至少满足2项）：
4. 成交量出现地量后放量
5. RSI(14) 从 < 30 回升至 > 35 且拐头向上
6. 出现基本面催化剂（政策利好、业绩超预期、行业拐点）
7. MACD 在零轴下方金叉且柱状图连续放大

买入仓位：分三批建仓
  第一批：计划仓位的 30%（右侧信号确认日）
  第二批：计划仓位的 30%（突破颈线/前期阻力位）
  第三批：计划仓位的 40%（回踩确认不破颈线）
止损位：买入价下方 3 × ATR(14)
4.4 三种策略适用场景
策略适用市场持有期时间止损风险等级收益预期
趋势突破牛市/强趋势1-4周5日未突破前高→出场中高
回调买入震荡上行2-8周8日未企稳→出场低-中中-高
底部右侧确认熊转牛初期1-6月15日未确认→出场高极高
4.5 目标价与盈亏比计算
核心公式：盈亏比 = 目标收益空间 / 止损空间，要求 >= 2:1
止损空间 = N × ATR(14)（从买入价到止损价的距离）
目标收益空间 = 目标价 - 买入价

目标价确定方法（按策略类型选择）：

趋势突破策略：
  目标价 = 突破位 + (突破位 - 前期回调最低点) × 1.0
  （即突破前一波段的涨幅等量投射）

回调买入策略：
  目标价 = 前高位置 或 MA(C, 20) 上方的阻力位
  （至少是止损空间的2倍以上才值得入场）

底部右侧确认策略：
  目标价 = 前期下跌起点到买入价的 38.2% 或 50% 斐波那契回撤位

示例：
  买入价 = 20元，ATR(14) = 0.8元，趋势突破（N=1.5）
  止损空间 = 1.5 × 0.8 = 1.2元（止损价18.8元）
  前波段低点18元，突破位20元，波段高度 = 2元
  目标价 = 20 + 2 = 22元
  盈亏比 = 2.0 / 1.2 = 1.67 → 不足 2:1，需谨慎
4.6 买入决策树
发现一只股票
  │
  ├─→ 触发排雷清单？ ── 是 → 直接跳过
  │                 └─ 否 ↓
  ├─→ 基本面符合标准？ ── 否 → 加入观察池，不操作
  │                   └─ 是 ↓
  ├─→ 大盘状态允许买入？ ── 否 → 加入观察池，等待
  │                      └─ 是 ↓
  ├─→ 出现买入信号？ ── 否 → 设置提醒价格，等待
  │                 └─ 是 ↓
  ├─→ 盈亏比 >= 2:1？ ── 否 → 跳过（目标空间不够）
  │                   └─ 是 ↓
  ├─→ 计算仓位：min(总资金 × 2% / ATR止损幅度, 25%)
  │
  └─→ 执行买入 + 立即设定止损位 + 记录交易计划
五卖出策略
5.1 止损规则（铁律，不可违反）
ATR 动态止损（核心方法）
用 ATR 替代固定百分比止损，自动适应不同股票的波动特性。
ATR(14) = 14日平均真实波动幅度
买入价 = P，止损价 = P - N × ATR(14)

N 的取值：
  趋势突破策略：N = 1.5（紧止损）
  回调买入策略：N = 2.0（适度止损）
  底部右侧确认策略：N = 3.0（宽止损）

示例：
  买入价 20元，ATR(14) = 0.8元
  趋势突破：止损价 = 20 - 1.5 × 0.8 = 18.8元（止损幅度 6%）
  回调买入：止损价 = 20 - 2.0 × 0.8 = 18.4元（止损幅度 8%）
固定百分比止损（辅助方法）
策略类型固定止损幅度
短线（趋势突破）买入价下方 5%
中线（回调买入）买入价下方 8%
长线（底部右侧确认）买入价下方 10%
其他止损规则
规则细节
技术止损跌破关键支撑位（均线/前低/趋势线），以先触发者为准
时间止损买入后 N 个交易日未按预期运行，出场（具体天数见 4.4 表格）
逻辑止损买入逻辑被证伪（如业绩暴雷、政策转向），立即出场
总仓位止损总账户回撤 > 10%，强制减仓至半仓；回撤 > 15%，空仓休息
止损优先级：取最严格（最靠近当前价）的止损位执行：
  止损价 = min(ATR止损价, 技术止损价, 固定百分比止损价)
5.2 止盈规则
跟踪止盈（趋势行情首选）
初始设定：跟踪止盈价 = 买入价 × (1 - 回撤比例)
每日更新（只上不下）：跟踪止盈价 = max(昨日值, 最高收盘价 × (1 - 回撤比例))
触发：收盘价 < 跟踪止盈价 → 次日开盘卖出

回撤比例：短线 8% | 中线 15% | 长线 20%

示例（买入20元，回撤比例8%）：
  Day1 收盘21 → 止盈 = 21 × 0.92 = 19.32（上移）
  Day2 收盘22 → 止盈 = 22 × 0.92 = 20.24（继续上移）
  Day3 收盘20.5 → 20.5 > 20.24 → 不触发
  Day4 收盘19.8 → 19.8 < 20.24 → 次日卖出
目标止盈（波段行情）
方法规则适用场景
目标止盈到达目标位卖出1/2，剩余启动跟踪止盈波段行情
信号止盈放量滞涨 / MACD死叉 / 顶部形态所有场景
分批止盈第一目标出30%，第二目标出30%，剩余跟踪止盈中长线
5.3 卖出优先级
1. 触发止损 → 立即卖出（当日收盘前或次日开盘）
2. 买入逻辑破坏 → 尽快卖出（当日或次日）
3. 止盈信号出现 → 执行止盈计划（可设条件单）
4. 发现更好机会 → 换股（仅当新机会盈亏比 ≥ 3:1）
六仓位管理
6.1 总仓位控制
大盘状态总仓位上限判定条件
牛市确认80-100%均线多头排列 + 市场广度指标共振
震荡偏多50-70%站上60日均线但未确认趋势
震荡偏空20-40%跌破60日均线但未确认熊市
熊市0-20%均线空头排列 + 广度指标全面走弱
6.2 个股仓位
规则标准
单只上限总资金的 25%（绝对硬性上限）
单只标准总资金的 10-15%（常规配置）
集中度同行业不超过总仓位的 40%
相关性持仓中同产业链股票不超过 3 只
持仓数量5-10 只
6.3 风险预算与仓位计算
核心原则：每笔交易的最大亏损不超过总资金的 2%。
单只仓位 = min(总资金 × 2% / 止损幅度, 总资金 × 25%)
止损幅度 = N × ATR(14) / 买入价

示例1（低波动股）：100万资金，买入价20元，ATR=0.5，趋势突破N=1.5
  止损幅度 = 3.75% → min(53.3万, 25万) = 25万（触发25%上限）

示例2（中等波动股）：100万资金，买入价30元，ATR=1.2，回调买入N=2.0
  止损幅度 = 8% → min(25万, 25万) = 25万（两个约束同时生效）

示例3（高波动股）：100万资金，买入价50元，ATR=3.0，底部右侧确认N=3.0
  止损幅度 = 18% → min(11.1万, 25万) = 11.1万（风险预算严格约束）
6.4 加减仓规则
操作条件动作
加仓浮盈 > 1.5 × ATR(14) + 趋势延续确认金字塔加仓（每次递减）
减仓浮盈从最高点回撤超过50%或信号走弱减至半仓
清仓触发止损或逻辑破坏全部卖出
补仓禁止亏损时绝不在亏损方向加仓止损而非补仓

7.2 铁律（零容忍）
#规则违反后果
1止损不可撤销 — 到了止损位必须卖小亏变大亏
2不追涨杀跌 — 没有信号不进场高位接盘/低位割肉
3不逆势满仓 — 熊市不加杠杆爆仓风险
4不在亏损仓位加仓 — 止损而非补仓亏损放大
5不过度交易 — 每月不超10次手续费吞噬利润
6不碰不懂的票 — 不跟风听消息盲目赌博
7不临时起意 — 所有计划盘前制定情绪化操作
7.3 心理管理
情绪触发场景应对方法
贪婪连续盈利，想加仓加杠杆回顾规则，严格执行仓位上限
恐惧连续亏损，不敢下单缩小仓位恢复信心，检查系统是否失效
后悔卖出后继续涨 / 未买入的涨了接受不确定性，关注过程而非结果
侥幸亏损持仓期待回本执行止损，市场不关心你的成本
疲劳盯盘过度，决策质量下降设定交易时段，其余时间不盯盘

九绩效评估与系统迭代
9.1 核心绩效指标
指标公式合格标准优秀标准
超额收益组合收益 - 沪深300收益> 0%超基准 5%+
年化收益率几何平均> 12%> 20%
最大回撤峰值到谷底最大跌幅< 15%< 10%
夏普比率(收益率-无风险)/波动率> 0.8> 1.5
卡尔玛比率年化收益/最大回撤> 1.0> 2.0
胜率盈利次数/总次数> 45%> 55%
盈亏比平均盈利/平均亏损> 1.5:1> 2.5:1
月度胜率盈利月数/总月数> 60%> 70%
基准说明：个人交易者的合理目标是持续跑赢沪深300指数 5-10个百分点。
9.2 系统失效判定
以下任一情况出现，暂停交易，全面复盘：

1. 连续 5 次交易止损 → 检查选股/买入条件
2. 单月亏损 > 8% → 检查仓位管理是否合规
3. 最大回撤 > 15% → 降低仓位，回归模拟盘
4. 月度胜率连续3月 < 30% → 系统可能不适应市场
5. 绩效连续3月跑输沪深300 → 重新评估策略
9.3 回测与验证框架
项目最低要求
回测时间跨度至少 3 年（覆盖牛熊周期）
样本量至少 50 次交易信号
滑点假设每笔交易扣除 0.5% 成本
资金曲线记录每笔交易后的资金曲线，计算最大回撤
信号 vs 执行分离区分"信号胜率"和"执行胜率"

9.4 迭代流程
月度复盘 → 识别亏损交易的共性原因
    │
    ├── 执行问题（未守纪律）→ 强化规则，不改动系统
    │   标志：信号正确但执行偏差 > 2%
    │
    ├── 选股问题（标的质量差）→ 调整筛选条件
    │   标志：胜率低但盈亏比正常
    │
    ├── 时机问题（买卖点不准）→ 优化技术信号参数
    │   标志：胜率低且盈亏比低
    │
    └── 市场问题（系统不适应）→ 暂停该策略
        标志：连续3月跑输基准

要素一句话
选股先排雷，再筛好公司，在好价格买入

卖出ATR动态止损铁律不可破，跟踪止盈按算法走
